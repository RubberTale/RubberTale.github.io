# SSML 发音校准与规避清单

为确保 Edge-TTS、Azure Speech 等 TTS 引擎不会出现低级发音错误，请遵循以下 `<sub alias="...">` 替换规约。

> ⚠️ **重要区分**：`<sub alias>` 只能解决「多音字、数字读法」。它**解决不了「TTS 同音错字」**——
> 即发音没错，但**转写成字幕时写错了字**。后者必须靠「第六步 字幕校对表」逐条 grep 校验。
> 文末第二节就是为此积累的真实错案库。

## 1. 化学式与连字符编号
- `顺式-1,4-聚异戊二烯` -> `<sub alias="顺式一四聚异戊二烯">顺式-1,4-聚异戊二烯</sub>`（严禁让 TTS 读成“一点四”或“十四”）
- `β-1,3-葡聚糖酶` -> `<sub alias="贝塔一三葡聚糖酶">β-1,3-葡聚糖酶</sub>`
- `pH 值` -> `<sub alias="P H 值">pH 值</sub>`

## 2. 生僻字与多音字
- `几丁质` -> `<sub alias="肌丁质">几丁质</sub>`（多音字“几”读第一声 jī）
- `橡胶烃` -> `<sub alias="橡胶听">橡胶烃</sub>`（烃读 tīng）
- `韧皮部` -> 韧皮部（正常读 rèn）
- `大戟科` -> `<sub alias="大几科">大戟科</sub>`（戟读 jǐ）
- `蒴果` -> `<sub alias="硕果">蒴果</sub>`（蒴读 shuò）

## 3. 数值、角度与单位
- `3° 至 7°` / `3 到 7 度` -> `<sub alias="三到七度">3 到 7 度</sub>`
- `10 到 15 个大气压` -> `<sub alias="十到十五个大气压">10 到 15 个大气压</sub>`
- `1.5 MPa` -> `<sub alias="一点五兆帕">1.5 MPa</sub>`
- `700% 甚至 900%` -> `<sub alias="百分之七百甚至百分之九百">700% 甚至 900%</sub>`
- `2 到 4 小时` -> `<sub alias="两到四小时">2 到 4 小时</sub>`
- `50 至 100 毫升` -> `<sub alias="五十到一百毫升">50 至 100 毫升</sub>`
- `20 至 40 克` -> `<sub alias="二十到四十克">20 至 40 克</sub>`
- `12,000 种` -> `<sub alias="一万两千多种">一万两千多种</sub>`
- 历史年份必须逐字确认：`公元前1600年` -> `<sub alias="公元前一千六百年">公元前1600年</sub>`

## 4. 气口与断句规范
- 逗号后：`<break time="200ms"/>`
- 强调重点后：`<break time="250ms~300ms"/>`
- 句号间：`</s><s>` 自动带有句尾降调；若需更长悬念，补充 `<break time="300ms"/>`
- 大幕间转场：`<break time="800ms"/>`

## 5. ⚠️ 真实错案库（TTS 同音错字，必须 grep 校验）

以下为 1.1 / 1.2 实战中**已经出现并混入成片字幕**的真实错误。生成新脚本的「字幕校对表」时，
**必须把下表全量纳入校验清单**，并按章节补充新条目。

| # | 正确写法 | 实际出现的误转写 | 危害等级 | 出处 |
|---|---|---|---|---|
| 1 | **汁液** | 枝叶 | 🔴 严重（歧义，读成"枝叶"完全变义） | 1.1 #99、1.2 #2 |
| 2 | **顺式-1,4-聚异戊二烯** | 顺势一四聚一五二烯 | 🔴 严重（构型字错 + 戊→五） | 1.2 |
| 3 | **熵弹性** | 商谈性 | 🔴 严重（物理核心概念被毁） | 1.2 |
| 4 | **固特异** | 故特意 | 🟠 中（人名） | 1.2 |
| 5 | **胶工** | 交工 | 🟠 中（职业名） | 1.2 |
| 6 | **乳胶** | （漏字）所流淌的地方 | 🟠 中（主语丢失） | 1.2 |
| 7 | **威慑 / 喷涌** | 喷涌（注：`显出` 应为 `析出`） | 🟡 轻（语义模糊） | 1.2 |

### 校验命令（UTF-8 读 SRT，逐条扫描）

```python
# -*- coding: utf-8 -*-
"""字幕错字校验：扫描 SRT 中的同音误转写"""
import re, io, sys

BLACKLIST = {
    '枝叶': '应为「汁液」',
    '顺势一四': '应为「顺式-1,4-」',
    '一五二烯': '应为「异戊二烯」',
    '商谈性': '应为「熵弹性」',
    '故特意': '应为「固特异」',
    '交工': '应为「胶工」',
}

def check(srt_path):
    text = io.open(srt_path, encoding='utf-8-sig').read()
    blocks = re.findall(
        r'\n(\d+)\n(\d\d:\d\d:\d\d,\d+) --> (\d\d:\d\d:\d\d,\d+)\n((?:.+\n?)+)', text)
    hits = 0
    for num, start, _, body in blocks:
        line = body.strip().replace('\n', ' ')
        for bad, fix in BLACKLIST.items():
            if bad in line:
                hits += 1
                print(f'  [{bad}] #{num} @ {start[3:]}  {line}  → {fix}')
    print(f'共 {len(blocks)} 条字幕，命中 {hits} 处疑似错字' if hits
          else f'✅ 共 {len(blocks)} 条字幕，未命中错字')
    return hits

if __name__ == '__main__':
    for p in sys.argv[1:]:
        print(f'=== {p} ===')
        check(p)
```

调用：`python 字幕校验.py "第二集/01.srt" "第二集/1788659131_9467.srt"`

或直接用 grep（快速版）：
```bash
grep -n -E "枝叶|顺势一四|一五二烯|商谈性|故特意|交工" *.srt
```

## 6. TTS 音频制作推荐参数

- **目标语速：260 字/分**（1.1 实测 258，1.2 实测 264）。SSML 里 `rate="-3%"` 在 Edge-TTS 下约得 260 字/分。
- ⚠️ **不要按脚本元信息里写的「200–210 字/分」估算时长**——那是文档里的声明值，与实际成片不符。
  正确换算：**预计时长(分钟) ≈ 旁白字数 ÷ 260**。
- 每句旁白对应一个独立 SRT 条目会更好剪（1.2 的 151 条 / 7:14，平均 2.9 秒/条）。
