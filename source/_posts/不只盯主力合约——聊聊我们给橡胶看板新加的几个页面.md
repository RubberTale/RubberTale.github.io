做橡胶研究久了，有一个直觉越来越强烈：**光盯主力合约，你看到的只是冰山一角。**

真正的钱——产业套保的钱、期现套利的钱、跨期配置的钱——大部分时候藏在那些你不太留意的非主力月份合约里。一个 03 合约上突然冒出来的几千手增仓，很可能比主力合约上几万手的日常翻搅更值得你警觉。

所以最近这段时间，我一直在折腾我们的 Power BI 橡胶投研看板，给它加了好几个新页面。今天写篇文章，把这些新东西好好聊一聊。

---

## 先说痛点：为什么只看主力合约不够用？

做 RU 的朋友应该都有体会。天胶的主力合约分布是典型的 1-5-9 格局，NR（20号胶）则是 10、11、12、01 好几个月份都很活跃，BR（顺丁橡胶）更接近逐月连续的模式。三个品种三种脾气，你没法用一套逻辑去硬套。

问题出在几个地方：

**第一，换月节奏。** 资金从近月往远月搬家的速率快慢，直接决定了近月交割博弈有多激烈、远月的升贴水能撑多久。这个过程不是某天突然发生的，而是在各合约间持仓此消彼长中慢慢演变的。你不摊开所有月份来看，根本感知不到。

**第二，非主力月份的异常信号。** 经验告诉我们，远月非主力合约上突然出现的大量增仓，往往是产业客户提前套保、或者套利资金暗中布局的先行指标。等这些信号传导到主力合约上被大家看到的时候，行情往往已经走了一大段了。

**第三，三个橡胶品种的结构差异太大。** RU 的仓单有新老胶年限约束、NR 是国际化定价品种、BR 是纯粹的化工合成胶——它们各自的合约持仓分布长得完全不一样，必须拆开来看才有意义。

想清楚这些以后，新页面的方向就很明确了。

---

## 新页面一：三个橡胶各合约持仓占比

这是这次更新的核心。

一句话概括：**把 RU、NR、BR 三个品种各自所有在挂合约的持仓量，用三个并排的树状图（Treemap）铺开来给你看。**

页面布局大概长这样：

```
┌──────────────────────────────────────────────────────────────────────┐
│ [RU 天然橡胶]      [NR 20号胶]       [BR 顺丁橡胶]     [交易日期]  │
│  RU2701 ████████    NR2611 ██████     BR2611 ██████     [日期切片]  │
│  RU2705 ████        NR2612 ████       BR2610 █████                 │
│  RU2609 ██          NR2701 ████       BR2701 ███                   │
│  RU2611 █           NR2610 ██         BR2612 █                     │
│  ...                ...               ...                          │
│                                                                    │
│  ──────── 底部导航栏（首页 / 行情 / 基差 / 库存 / 宏观）────────── │
└──────────────────────────────────────────────────────────────────────┘
```

每个色块的面积严格对应那个合约的持仓量大小。一打开页面，你立刻就能看到：

- **RU 这边**，2701 合约（01 主力）占了一大块，2705 还在蓄力阶段，近月的 2609 在交割注销前还压着一些持仓——三者之间的比例关系一目了然；
- **NR 那边**，持仓明显更"均匀"，2611、2612、2701 好几个月份都有不小的体量，这就是 20 号胶作为国际化品种的典型特征；
- **BR 则是**近月双核（2610、2611）主导的格局，后面的月份持仓很快衰减。

右边放了一个日期切片器，默认选的是最新交易日。你可以往回拨到任何一天——比如上个月那波急跌的起点——看看当时的持仓结构和今天有什么不同。资金到底是怎么搬的，搬到哪里去了，一切都在里面。

说实话，这个页面做出来之后，我自己用得最多。很多时候，你盯着 K 线图和成交量看不出门道，但把全合约持仓分布铺开一对比，思路一下就清晰了。

---

## 新页面二：三个橡胶的成交与持仓横向对比

这个页面解决的是另一个问题：**资金在天胶、20号胶和顺丁之间到底怎么流转的？**

我放了四组柱状图，分别对比三个品种的成交量、成交金额、持仓量和持仓金额。简单直接。

这个页面的实际用处在于，当你看到某一天 RU 的持仓金额在缩而 BR 的在涨，脑子里马上就会跳出来一个问题：是天胶的产业客户在平仓离场？还是跨品种的替代套利资金在搬家？这种跨品种的资金轮动信号，光看单一品种的 K 线根本捕捉不到。

---

## 新页面三：全品种成交持仓占比全景

把视野再拉远一层——不只是橡胶三兄弟之间比，而是把橡胶放到整个国内商品期货大盘里定个位。

有色、黑色、能化、农产品，各个板块今天资金是在往里涌还是往外撤？橡胶在全市场的资金占比是变大了还是变小了？

这个页面帮你快速做一个判断：**眼前这波行情，到底是橡胶自己的基本面在驱动，还是整个能化板块甚至全市场的流动性在共振？** 搞清楚这个问题，你对行情持续性的判断会完全不一样。

## 还有一些地理空间类的升级

除了交易数据层面，这次还顺手把产业链空间分布类的看板往前推了推：

- **中国轮胎产能地图**：用 3D 柱状在地图上标出山东、江苏、浙江、安徽这些核心轮胎基地的产能和企业分布，一眼就能看出下游消费的重心在哪里；
- **全球产胶国产量分布**：泰国、印尼、越南、老挝、柬埔寨、科特迪瓦……各个主产区的种植面积和产出密度，从国家级一直下钻到地市级；
- **丁二烯装置与开工率监测**：顺丁橡胶的上游是丁二烯，谁家装置在检修、整体开工率多少，直接影响 BR 的供应预期。

这些页面和交易持仓类页面之间通过底部统一导航栏串在一起，随时可以来回切换。从"盘面上钱怎么动"到"地上胶怎么产"，基本上一套看板就能覆盖了。
